Transaction descriptions are Fernet-encrypted in SQLite using your master key at ~/.config/gk/master.key.

DIARY MODULE
Photo captions · LLM writer · Weekly auto-draft · Draft → approve workflow
HOW IT WORKS

1. Your photos are scanned for EXIF date/time and GPS.
2. moondream (local vision model) captions each photo.
3. qwen3:1.7b writes a warm first-person diary entry from the captions.
4. Draft is saved — you review and approve it.

VOICE & LANGUAGE
faster-whisper mic recording · Marathi · Hindi · Devanagari auto-detect
SETUP

faster-whisper is already installed. The 74 MB base model auto-downloads on first /voice call.
Requires: arecord (ALSA) — usually pre-installed on Ubuntu/Debian.

VOICE COMMANDS (type in CLI)
COMMANDDESCRIPTION

HOW DETECTION WORKS
Any Devanagari character (U+0900–U+097F) in your query triggers the language hint. qwen3:1.7b replies in the same script.
